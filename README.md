# NOVRA VIDEO — Local V1

مكتبة فيديوهات محلية تعمل من خلال متصفح الهاتف وخادم محلي بسيط.

## المتطلبات
- Termux
- Python 3
- متصفح حديث يدعم OPFS، ويفضل Chrome على Android

## التشغيل
```bash
cd ~/NOVRA-VIDEO
python server.py
```
افتح:
`http://127.0.0.1:8765`

اترك Termux يعمل أثناء استخدام الموقع. لإيقاف الخادم اضغط `Ctrl+C`.

## التخزين
- ملفات الفيديو تحفظ في Origin Private File System (OPFS) الخاص بأصل الموقع.
- بيانات المكتبة والصور المصغرة تحفظ في IndexedDB.
- لا تُنسخ الملفات تلقائيًا إلى معرض الهاتف.
- تصدير بيانات المكتبة لا يصدّر ملفات الفيديو نفسها.

## استيراد الروابط
يقبل الإصدار الأول روابط ملفات فيديو مباشرة عبر HTTP/HTTPS. لا يدعم صفحات YouTube أو منصات البث المحمية أو روابط تتطلب تسجيل دخول. بعض الخوادم قد تمنع الاستيراد أو تستخدم تحويلات Redirect غير مدعومة.

## ملاحظات مهمة
- يجب فتح الموقع دائمًا من نفس العنوان `http://127.0.0.1:8765` حتى يرى المتصفح نفس مساحة التخزين.
- لا تمسح بيانات الموقع أو بيانات المتصفح إذا كنت تريد الاحتفاظ بالمكتبة.
- المتصفح قد يفرض حدودًا على التخزين أو يحذف بيانات المواقع في حالات نادرة؛ احتفظ بنسخ أصلية من فيديوهاتك.
- هذا إصدار محلي لجهاز واحد. مشاركة المكتبة مع أجهزة أخرى تحتاج لاحقًا إلى خادم شبكة محلية ونظام صلاحيات.
- يدعم التشغيل حسب صيغ الفيديو التي يدعمها المتصفح نفسه؛ MP4/H.264 وWebM خيارات مناسبة عادة.
